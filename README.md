# Simple Interest Calculator

A small Bash project that calculates simple interest from user-provided principal, annual interest rate, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Run

```bash
bash simple-interest.sh
```

Enter the principal amount, annual interest rate (in percent), and time period (in years) when prompted.
